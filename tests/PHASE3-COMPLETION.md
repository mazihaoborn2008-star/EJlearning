## 9–11. 题库、自适应定位与测试

每种语言 **192 道定位题**：原 12 道保留，新增 168 道实际意义／情境选择题及 12 道句子补全。支持自然表达选择、意思识别、短语选择、情境回应、短对话理解、结构选择和句子补全。每种语言另有 183 道主题小测题。

定位从 Level 3 开始，以六个候选能力等级的贝叶斯权重积累答题证据，结合题目难度、正误、相邻难度覆盖和信心判断。选择围绕当前估计移动，每四题探测相邻难度，优先补充较少覆盖的主题。会话种子只用于同等题目的稳定排序，不代替自适应逻辑。

至少 8 题；信心及覆盖足够时提前结束；通常 8–15 题；硬上限 18。单个难题的正误不会直接决定 Level 1 或 6。返回等级、中文能力说明、起始难度、推荐主题和易懂的证据摘要；首页再结合已有进度选择实际学习项。

**定位测试通过**：初学者、中级、高级、连续错误、连续成功、混合表现、边界不确定、提前结束、硬上限、确定性、英语／日语独立、伪造／重放／并发答案、错误会话、过期、格式异常。700 次双语言不同种子模拟保持预期等级。该模拟验证实现行为，不代表真实人群的心理测量有效性。

会话由服务器掌控，以随机 UUID 标识，版本比较更新防止重复计分。最近一次完全相同的提交可安全重试；不同答案重放返回 409。30 分钟过期；完成后立即清除答题历史；过期行在新会话启动和每 30 分钟的 Worker 清理任务中删除。服务器清理任务只维护临时数据，不属于学习提醒、SRS 或 Phase 4。

## 12–13. 推荐算法与测试

每种语言独立根据其等级、内容难度、主题进度、学习／掌握／复习状态、最近学习、上次位置及小测弱项排序。主题与类型重复受到扣分；四个核心项目加一项较易巩固和一项适度挑战，复习需求可优先。已掌握内容明显降权，内容不足时允许再次巩固。

**推荐测试通过**：新 Level 1／4／6、EN5／JA2、部分已完成主题、大量待复习、检查点弱项、近期学习、已掌握、无定位、空列表及手动主题筛选。不同能力资料确实生成不同推荐，并有主题多样性。队列每种语言最多 6 项；学习者可随时自由浏览任意难度，不存在硬锁。

## 14. 主题小测

每个主题、每种语言抽取覆盖难度范围的 8 个不同问题，服务器客观评分，结果列出薄弱 Concept。错题将该语言的对应学习项标为待复习并影响推荐。答对不自动把整个主题标为掌握，也不修改另一语言。

全部 **14 × 2 = 28** 个主题／语言组合已在本地及 staging 完成验证，测试精确检查错误 Concept ID、分数、题数及语言／主题归属。

## 16. API 变更

| API | 用途 |
|---|---|
| `GET /api/topics` | 主题 |
| `GET /api/concepts?topic=...` | 轻量目录：语义、类型、双语言难度 |
| `GET /api/concepts/:id` | 按需完整卡片 |
| `POST /api/placement/start` | 开始独立定位 |
| `POST /api/placement/answer` | 提交并获取下一题／结果 |
| `POST /api/recommendations` | 基于单一语言资料推荐 |
| `POST /api/checkpoint/start` | 主题小测 |
| `POST /api/checkpoint/answer` | 小测下一题／薄弱项结果 |

统一 `{data:...}`／`{error:...}`。严格验证类型及未知字段，JSON 请求上限 16 KiB，参数化 D1 查询。发布内容 GET 缓存 60 秒；推荐／测评 `no-store`。客户端不接收答案键、隐藏权重或逐题定位正误。旧固定定位 API 明确返回 410，引导刷新；该行为为有意替代。完整契约见 [README](../README.md)。

**质量限制：新内容由模型编写和复查，未经过独立人工双语语言学审校。** 自动审计验证结构与读音对齐，不能证明所有自然度、IPA 或难度标签无误。定位难度同样尚未用真实学习者校准。没有把机器审查宣称为人工语言确定性。
